# Oyugi Mourice — Portfolio

Personal portfolio of Oyugi Mourice Odhiambo, Software Engineer. Live at **https://oyugi.netlify.app**.

Built with plain HTML, CSS and JavaScript (Typed.js and ScrollReveal for animation) and hosted on Netlify. The contact form uses Netlify Forms, so submissions appear in the Netlify dashboard under **Forms**.

## Run locally

Open `index.html` in a browser, or run `netlify dev` to test the contact form locally.
